### Thesis

| Plane | What it solves |
| :--- | :--- |
| **Egress reputation** | Datacenter boxes fail fraud/geo checks; agents need provable, policy-gated exit paths |
| **Mailbox identity** | OTP and verification require durable agent-owned inboxes — not shared personal mail |
| **Principal vs operator** | KYC/tax/payout stay with the human; agents get operator surfaces that never leak home PII |
| **Fleet handoff** | Agents coordinate via structured artifacts, not English spam between processes |
| **Prove before ship** | ADRs + healthchecks + tests — reject generate-and-dump |

**Minimum viable digital identity for most surfaces:** email that receives mail + IP reputation that isn't an abused datacenter range. Frontier stacks add SMS, OAuth app identity, payment instruments, and long-lived persona consistency.
